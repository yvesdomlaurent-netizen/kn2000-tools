🎛️ APC Key 25 mk2 — surface de contrôle live

Choisis les ports MIDI de l'APC (surface de contrôle = le 2e port « APC Key 25 mk2 », pas le keybed). Les 3 pads de la 1re colonne (bas → haut) = RIGHT1 / RIGHT2 / LEFT : sélectionner une part qui joue une Sound Memory y charge le slot en lecture et rend les knobs actifs dessus. Les knobs ajustent les paramètres en direct (écriture live si 🔒 armé, avec ⚡ auto-apply). 4 banques de 8 knobs = 32 mappings (les boutons Knob Control changent la banque — à apprendre s'ils émettent).

Knobs — 4 banques × 8

Par banque : « 🎓 CC » = clique puis tourne chaque knob une fois (les 8 numéros CC sont capturés) ; « 🎓 bouton » = clique puis presse le bouton Knob Control de l'APC (s'il n'émet rien, la banque se choisit en cliquant le bouton de la ligne). La banque active est surlignée.

Pads — 1re colonne = parts · les autres = ON/OFF

LED par type : vert = tones · jaune = vibrato · orange = distortion · bleu = effect · magenta = modulation · turquoise = controllers. La LED du pad s'allume quand la fonction est ON. Les pads des autres colonnes sont libres : choisis une action dans chaque liste.
