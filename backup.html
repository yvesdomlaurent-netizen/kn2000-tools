📚 Catalogue — croisement « ce qui réside dans le KN2000 » ↔ « ce qui doit y aller »

Catalogue —
Sauvegarde de patches : un patch = le contenu d'UNE aire + nom + date. Si le contenu est identique au patch précédent → seule la date est mise à jour ; s'il diffère → nouvelle version (l'ancienne n'est jamais écrasée, sauf suppression explicite 🗑).

🗂️ Bibliothèque — conteneur master unique, vues et échanges croisés

Principe : la vérité binaire est unique (le master), chaque outil n'est qu'une vue. Fichiers autonomes, auto-documentés, pensés pour une future appli Android (aucun contexte navigateur requis pour décoder).
Dossier repli : téléchargements
Dossier mémorisé par le navigateur (IndexedDB) — partagé avec le Sound Editor (même base) : un seul choix de dossier pour les deux outils. Sans dossier, repli téléchargement / sélecteur classique.
Master —
Le master kn2000-master-v1 = la vérité binaire : areas (blocs bruts hex, octets originaux, '--' = manquant) + sons (36 slots nommés, 144 o). Toutes les sections sont optionnelles pour un décodeur externe.
Importer —
Package kn2000_package_*.json (raw_hex 5184 o) → patch Sound (⚠ sans l'entête 80 o : restauration complète impossible depuis un package seul, le différentiel fonctionne) · Export banque → patch + 36 noms · Catalogue de sonorités → sons nommés · Catalogue/Master → patches par aire.
