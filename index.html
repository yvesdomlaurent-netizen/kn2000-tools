🎹 KN2000 Tools

Utilitaires Web MIDI pour le clavier Technics SX-KN2000 — dans le navigateur, sans installation. Compatible Chrome/Edge desktop (Web MIDI avec sysex ; Firefox ne supporte pas le sysex).

Sound Editor

Éditeur de sons pour les banques personnelles Memory A/B : lecture/écriture des 36 slots Sound Memory (sysex, 144 octets par son), écrans General/Tone/Effect, schémas d'enveloppe, surface Akai APC Key 25 mk2 (8 banques × 8 knobs, pads, LEDs par fonction), dump de banque et packages JSON.

v0.9.11 📖 Documentation

Panel Console

Console de pilotage : sonorités, rythme, Techni-Chord, Panel Memory, lecture d'état et bibliothèque d'ensembles.

v1.0 📖 Documentation
