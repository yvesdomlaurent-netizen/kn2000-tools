📖 Sound Editor — Aide / Help

🚀 Démarrage rapide

  1. Ouvrir la page dans Chrome ou Edge desktop (Web MIDI avec sysex requis — Firefox ne supporte pas le sysex ; pas de support mobile).
  2. Brancher l'interface MIDI USB du KN2000, puis cliquer 🔄 Ports et vérifier les entrées/sorties.
  3. Cliquer 🔌 Connecter : l'outil teste la liaison (lecture du slot courant, capture 📸 de l'original) et n'affiche « ● connecté » que si le KN2000 répond.
  4. Choisir un slot (A-1 → B-18) : lecture automatique du son.
  5. Modifier avec les curseurs et switches des onglets GENERAL / TONE / EFFECT. Par défaut, tout reste à l'écran ; pour écrire dans le clavier, armer l'écriture avec 🔒 Écriture (le cadenas devient 🔓).
⚠️ Avant toute écriture : faire un dump de sauvegarde de la banque (onglet BANQUE → Dump banque) ou un export. Le Sound Editor écrit dans les Sound Memory A/B du KN2000.
💡 L'option ⚡ Auto-appliquer recharge après chaque écriture le son en cours sur les parts du clavier qui le jouent (nécessite « Realtime sysex » sur ON dans le KN2000).
💡 Sans clavier, le bouton 🧪 Exemple A-1 usine charge un son d'exemple pour explorer les écrans.
⚠️ Mémoire volatile : le KN2000 ne conserve les sons que ~80 minutes hors tension. Après une coupure prolongée, les réglages usine reviennent — archive tes sons (💾 package, catalogue) pour pouvoir les renvoyer (📤) après chaque remise sous tension.

📚 Fonctions détaillées

Onglet GENERAL

  • 🗺️ Cartographie 144 octets : nom (16 caractères), octave shift, controllers, vibrato, auto bend & trill, modulation, digital effect — correspond aux écrans du manual Technics (p.24/30/31 + Digital Effects).
  • 📸 Session — Original : la première lecture d'un slot capture automatiquement l'original (144 octets). À tout moment : « ↩️ Rétablir l'original » renvoie l'original dans la machine, « ✅ Garder le nouveau son » valide la modification. Un original par slot, conservé entre rechargements de page.
  • ✍️ Nom : édition du nom du son, écriture séparée via le bouton « nom » (écriture armée requise).
  • 📍 Lire l'état : affiche quel son jouent RIGHT1 / RIGHT2 / LEFT, indépendamment du son édité.

Onglet TONE (1st · 2nd · sub)

  • Édition des trois tones : paramètres, enveloppes avec schémas visuels et courbes.
  • Code couleur : champ confirmé · partiel · inconnu.

Onglet EFFECT

  • Digital Effects : sélection, paramètres et mix, selon la cartographie établie sur la machine.

Onglet BANQUE (36 slots)

  • 📥 Dump banque : lit les 36 slots du clavier (5 184 octets) et les met en cache.
  • 📤 Envoi banque : écrit les 36 slots vers le clavier (écriture armée requise).
  • 📂 Import / export de banque au format JSON.

📚 Catalogue de sonorités

  • Sons isolés (144 octets chacun) : importer, exporter, copier d'un slot vers un autre.

Onglet APC — Akai APC Key 25 mk2

  • 🎛️ Knobs — 8 banques × 8 (64 paramètres pilotables). Apprentissage (« 🎓 CC ») : tourner les 8 knobs un par un ; « 🎓 bouton » : lier n'importe quel bouton de l'APC (Knob Control, Track, Scene, Stop, Play… ou un pad) comme sélecteur de cette banque. Chaque knob est ensuite assigné à un paramètre via le menu déroulant (74 paramètres disponibles : enveloppes complètes, KF, filtres des 3 tones, vibrato, auto bend, modulation, distortion, reverb, FX).
  • 🎛️ Pads : 1re colonne = parts du clavier (RIGHT1/RIGHT2/LEFT) ; les autres pads pilotent des ON/OFF (tones, vibrato, modulation, distortion, effect, glide, wheel…).
  • 🎨 LEDs en continu : chaque pad assigné reste allumé à la couleur de sa fonction (état OFF) ; la LED passe au vert quand la fonction est ON ; un pad libre est éteint. Un pad utilisé comme sélecteur de banque s'affiche en gris (banque inactive) ou vert (banque active). Couleurs paramétrables fonction par fonction (palette de 12 couleurs).
  • 💾 Export / import de la config APC (JSON) : copie toute la config (banques, knobs, pads, couleurs, ports) d'une origine/navigateur/PC à un autre.
  • Encodage des knobs configurable (2-complément ou absolu, inversion).
💡 Le paramétrage APC est mémorisé dans le navigateur (localStorage) — propre à chaque origine (localhost ≠ github.io) : utiliser l'export/import JSON pour le copier entre les deux.
💡 Après un rebranchement USB, Windows peut renuméroter les ports MIDI : si le port APC mémorisé ne correspond plus (ou pointe désormais le port du KN2000), l'outil le détecte et réinitialise la config APC avec un message dans le journal — il suffit de rechoisir le port dans l'onglet APC.

Journal sysex

  • 📜 Le journal affiche tout le trafic MIDI. Utile pour diagnostiquer une connexion ou découvrir des commandes.

🧷 Prérequis côté clavier

  • KN2000 : « Realtime sysex » sur ON pour la lecture automatique et l'auto-appliquer.
  • Interface MIDI USB reliée au port MIDI du KN2000.

❓ Dépannage

  • Le KN2000 n'apparaît pas dans les ports : vérifier le câble/Interface, cliquer 🔄 Ports.
  • « ⚠ pas de réponse » après 🔌 Connecter : l'outil n'a pas reçu de réponse du KN2000. Vérifier les ports In/Out (🔄 Ports), le câble MIDI, le branchement USB de l'interface, et que le clavier est allumé. Après tout rebranchement USB, cliquer 🔄 Ports.
  • Lecture auto ne marche pas : vérifier « Realtime sysex » sur ON.
  • La connexion se dégrade puis tombe : rebrancher l'interface MIDI sur un autre port USB (éviter de partager un hub USB non alimenté avec d'autres périphériques MIDI), redémarrer le clavier, puis 🔄 Ports → 🔌 Connecter.
  • APC : knobs sans effet : vérifier l'assignation des paramètres dans l'onglet APC et l'encodage.
  • APC : LEDs des pads n'apparaissent pas : vérifier que « APC Out » est le port de la surface de contrôle (retours LED), puis refaire une action sur un pad.
  • APC : un pad ON/OFF ne change pas de couleur à l'appui : vérifier que sa couleur fonction n'est pas le vert (couleur réservée à l'état ON) — la changer dans l'éditeur de couleurs.
  • Dump incomplet : le dump doit totaliser 5 184 octets ; relancer le dump.
  • Sous Firefox, rien ne se passe : Firefox ne supporte pas le sysex Web MIDI — utiliser Chrome ou Edge.

🚀 Quick start

  1. Open the page in Chrome or Edge desktop (Web MIDI with SysEx required — Firefox does not support SysEx; no mobile support).
  2. Connect the KN2000's USB MIDI interface, click 🔄 Ports and check the inputs/outputs.
  3. Click 🔌 Connect: the tool tests the link (reads the current slot, original is captured 📸) and only shows “● connected” if the KN2000 answers.
  4. Pick a slot (A-1 → B-18): the sound loads automatically.
  5. Edit with the sliders and switches of the GENERAL / TONE / EFFECT tabs. By default everything stays on screen; to write to the keyboard, arm writing with 🔒 Writing (the padlock turns 🔓).
⚠️ Before any write: make a bank backup dump (BANK tab → Bank dump) or an export. The Sound Editor writes to the KN2000's Sound Memory A/B.
💡 The ⚡ Auto-apply option reloads the edited sound onto the keyboard parts playing it after each write (requires “Realtime sysex” ON on the KN2000).
💡 Without a keyboard, the 🧪 Factory A-1 example button loads a sample sound to explore the screens.
⚠️ Volatile memory: the KN2000 only keeps sounds ~80 minutes after power-off; factory settings return afterwards. Archive your sounds (💾 package, catalogue) so you can send them back (📤) after any extended power-off.

📚 Detailed features

GENERAL tab

  • 🗺️ 144-byte mapping: name (16 chars), octave shift, controllers, vibrato, auto bend & trill, modulation, digital effect — matches the Technics manual screens (p.24/30/31 + Digital Effects).
  • 📸 Session — Original: the first read of a slot automatically captures the original (144 bytes). At any time: “↩️ Restore original” sends the original back to the machine, “✅ Keep new sound” validates the change. One original per slot, kept across page reloads.
  • ✍️ Name: sound name editing, written separately via the “name” button (armed writing required).
  • 📍 Read state: shows which sound RIGHT1 / RIGHT2 / LEFT are playing, independently of the edited sound.

TONE tab (1st · 2nd · sub)

  • Editing of the three tones: parameters, envelopes with visual diagrams and curves.
  • Colour code: confirmed field · partial · unknown.

EFFECT tab

  • Digital Effects: selection, parameters and mix, based on the mapping established on the machine.

BANK tab (36 slots)

  • 📥 Bank dump: reads all 36 slots from the keyboard (5,184 bytes) and caches them.
  • 📤 Bank send: writes the 36 slots back to the keyboard (armed writing required).
  • 📂 Bank import / export as JSON.

📚 Sound catalogue

  • Isolated sounds (144 bytes each): import, export, copy from one slot to another.

APC tab — Akai APC Key 25 mk2

  • 🎛️ Knobs — 8 banks × 8 (64 controllable parameters). Learning (“🎓 CC”): turn each of the 8 knobs; “🎓 button”: link any APC button (Knob Control, Track, Scene, Stop, Play… or a pad) as this bank's selector. Each knob is then assigned to a parameter via the dropdown (74 parameters available: full envelopes, KF, filters of all 3 tones, vibrato, auto bend, modulation, distortion, reverb, FX).
  • 🎛️ Pads: first column = keyboard parts (RIGHT1/RIGHT2/LEFT); other pads drive ON/OFF switches (tones, vibrato, modulation, distortion, effect, glide, wheel…).
  • 🎨 Continuous LEDs: each assigned pad stays lit with its function's colour (OFF state); the LED turns green when the function is ON; a free pad is off. A pad used as a bank selector shows gray (inactive bank) or green (active bank). Colours are configurable per function (12-colour palette).
  • 💾 APC setup export / import (JSON): copies the whole setup (banks, knobs, pads, colours, ports) across origins/browsers/PCs.
  • Knob encoding configurable (two's complement or absolute, inversion).
💡 The APC setup is stored in the browser (localStorage) — specific to each origin (localhost ≠ github.io): use the JSON export/import to copy it between the two.
💡 After replugging USB, Windows may renumber the MIDI ports: if the remembered APC port no longer matches (or now points to the KN2000's port), the tool detects it and resets the APC setup with a message in the log — just pick the port again in the APC tab.

SysEx log

  • 📜 The log shows all MIDI traffic. Useful to diagnose a connection or discover commands.

🧷 Keyboard-side requirements

  • KN2000: “Realtime sysex” ON for automatic reading and auto-apply.
  • USB MIDI interface connected to the KN2000's MIDI port.

❓ Troubleshooting

  • KN2000 not listed in ports: check cable/interface, click 🔄 Ports.
  • “⚠ no reply” after 🔌 Connect: the tool got no answer from the KN2000. Check the In/Out ports (🔄 Ports), the MIDI cable, the interface's USB connection, and that the keyboard is on. After any USB replug, click 🔄 Ports.
  • Auto-read not working: check “Realtime sysex” is ON.
  • Connection degrades then drops: replug the MIDI interface into another USB port (avoid sharing an unpowered USB hub with other MIDI devices), restart the keyboard, then 🔄 Ports → 🔌 Connect.
  • APC: knobs do nothing: check parameter assignments in the APC tab and the encoding mode.
  • APC: pad LEDs don't show: make sure “APC Out” is the control surface's port (LED returns), then act on a pad again.
  • APC: an ON/OFF pad doesn't change colour when pressed: check that its function colour isn't green (reserved for the ON state) — change it in the colour editor.
  • Incomplete dump: a dump must total 5,184 bytes; run the dump again.
  • Nothing happens under Firefox: Firefox does not support Web MIDI SysEx — use Chrome or Edge.
