📖 Sound Editor — Aide / Help

🚀 Démarrage rapide

  1. Ouvrir la page dans Chrome, Edge ou Firefox desktop (Web MIDI requis — pas de support mobile).
  2. Brancher l'interface MIDI USB du KN2000, puis cliquer 🔄 Ports et vérifier les entrées/sorties.
  3. Cliquer 🔌 Connecter : le slot courant est lu automatiquement (capture 📸 de l'original).
  4. Choisir un slot (A-1 → B-18) : lecture automatique du son.
  5. Modifier avec les curseurs et switches des onglets GENERAL / TONE / EFFECT. Par défaut, tout reste à l'écran ; pour écrire dans le clavier, armer l'écriture avec 🔒 Écriture (le cadenas devient 🔓).
⚠️ Avant toute écriture : faire un dump de sauvegarde de la banque (onglet BANQUE → Dump banque) ou un export. Le Sound Editor écrit dans les Sound Memory A/B du KN2000.
💡 L'option ⚡ Auto-appliquer recharge après chaque écriture le son en cours sur les parts du clavier qui le jouent (nécessite « Realtime sysex » sur ON dans le KN2000).
💡 Sans clavier, le bouton 🧪 Exemple A-1 usine charge un son d'exemple pour explorer les écrans.

📚 Fonctions détaillées

Onglet GENERAL

  • 🗺️ Cartographie 144 octets : nom (16 caractères), octave shift, controllers, vibrato, auto bend & trill, modulation, digital effect — correspond aux écrans du manual Technics (p.24/30/31 + Digital Effects).
  • 📸 Session — Original : la première lecture d'un slot capture automatiquement l'original (144 octets). À tout moment : « ↩️ Rétablir l'original » renvoie l'original dans la machine, « ✅ Garder le nouveau son » valide la modification. Un original par slot, conservé entre rechargements de page.
  • ✍️ Nom : édition du nom du son, écriture séparée via le bouton « nom » (écriture armée requise).
  • 📍 Lire l'état : affiche quel son jouent RIGHT1 / RIGHT2 / LEFT, indépendamment du son édité.

Onglet TONE (1st · 2nd · sub)

  • Édition des trois tones : paramètres, enveloppes avec schémas visuels et courbes.
  • Code couleur : champ confirmé · partiel · inconnu.

Onglet EFFECT

  • Digital Effects : sélection, paramètres et mix, selon la cartographie établie sur la machine.

Onglet BANQUE (36 slots)

  • 📥 Dump banque : lit les 36 slots du clavier (5 184 octets) et les met en cache.
  • 📤 Envoi banque : écrit les 36 slots vers le clavier (écriture armée requise).
  • 📂 Import / export de banque au format JSON.

📚 Catalogue de sonorités

  • Sons isolés (144 octets chacun) : importer, exporter, copier d'un slot vers un autre.

Onglet APC — Akai APC Key 25 mk2

  • 🎛️ Knobs : 4 banques × 8 knobs. Apprentissage (« 🎓 CC ») : tourner les 8 knobs un par un ; bouton « 🎓 bouton » pour lier le bouton Knob Control de chaque banque. Chaque knob est ensuite assigné à un paramètre via le menu déroulant.
  • 🎛️ Pads : 1re colonne = parts du clavier (RIGHT1/RIGHT2/LEFT) ; les autres pads pilotent des ON/OFF (vibrato, modulation, distortion, effect…). LEDs : vert = actif, blanc = part sélectionnée.
  • Encodage des knobs configurable (2-complément ou absolu, inversion).
💡 Le paramétrage APC est mémorisé dans le navigateur (localStorage) — il est propre à chaque origine (localhost ≠ github.io) : à refaire une fois par site.

Journal sysex

  • 📜 Le journal affiche tout le trafic MIDI. Utile pour diagnostiquer une connexion ou découvrir des commandes.

🧷 Prérequis côté clavier

  • KN2000 : « Realtime sysex » sur ON pour la lecture automatique et l'auto-appliquer.
  • Interface MIDI USB reliée au port MIDI du KN2000.

❓ Dépannage

  • Le KN2000 n'apparaît pas dans les ports : vérifier le câble/Interface, cliquer 🔄 Ports.
  • Lecture auto ne marche pas : vérifier « Realtime sysex » sur ON.
  • APC : knobs sans effet : vérifier l'assignation des paramètres dans l'onglet APC et l'encodage.
  • Dump incomplet : le dump doit totaliser 5 184 octets ; relancer le dump.

🚀 Quick start

  1. Open the page in Chrome or Edge desktop (Web MIDI required — no mobile support).
  2. Connect the KN2000's USB MIDI interface, click 🔄 Ports and check the inputs/outputs.
  3. Click 🔌 Connect: the current slot is read automatically (original is captured 📸).
  4. Pick a slot (A-1 → B-18): the sound loads automatically.
  5. Edit with the sliders and switches of the GENERAL / TONE / EFFECT tabs. By default everything stays on screen; to write to the keyboard, arm writing with 🔒 Writing (the padlock turns 🔓).
⚠️ Before any write: make a bank backup dump (BANK tab → Bank dump) or an export. The Sound Editor writes to the KN2000's Sound Memory A/B.
💡 The ⚡ Auto-apply option reloads the edited sound onto the keyboard parts playing it after each write (requires “Realtime sysex” ON on the KN2000).
💡 Without a keyboard, the 🧪 Factory A-1 example button loads a sample sound to explore the screens.

📚 Detailed features

GENERAL tab

  • 🗺️ 144-byte mapping: name (16 chars), octave shift, controllers, vibrato, auto bend & trill, modulation, digital effect — matches the Technics manual screens (p.24/30/31 + Digital Effects).
  • 📸 Session — Original: the first read of a slot automatically captures the original (144 bytes). At any time: “↩️ Restore original” sends the original back to the machine, “✅ Keep new sound” validates the change. One original per slot, kept across page reloads.
  • ✍️ Name: sound name editing, written separately via the “name” button (armed writing required).
  • 📍 Read state: shows which sound RIGHT1 / RIGHT2 / LEFT are playing, independently of the edited sound.

TONE tab (1st · 2nd · sub)

  • Editing of the three tones: parameters, envelopes with visual diagrams and curves.
  • Colour code: confirmed field · partial · unknown.

EFFECT tab

  • Digital Effects: selection, parameters and mix, based on the mapping established on the machine.

BANK tab (36 slots)

  • 📥 Bank dump: reads all 36 slots from the keyboard (5,184 bytes) and caches them.
  • 📤 Bank send: writes the 36 slots back to the keyboard (armed writing required).
  • 📂 Bank import / export as JSON.

📚 Sound catalogue

  • Isolated sounds (144 bytes each): import, export, copy from one slot to another.

APC tab — Akai APC Key 25 mk2

  • 🎛️ Knobs: 4 banks × 8 knobs. Learning (“🎓 CC”): turn each of the 8 knobs; “🎓 button” links each bank's Knob Control button. Each knob is then assigned to a parameter via the dropdown.
  • 🎛️ Pads: first column = keyboard parts (RIGHT1/RIGHT2/LEFT); other pads drive ON/OFF switches (vibrato, modulation, distortion, effect…). LEDs: green = active, white = selected part.
  • Knob encoding configurable (two's complement or absolute, inversion).
💡 The APC setup is stored in the browser (localStorage) — it is specific to each origin (localhost ≠ github.io): redo it once per site.

SysEx log

  • 📜 The log shows all MIDI traffic. Useful to diagnose a connection or discover commands.

🧷 Keyboard-side requirements

  • KN2000: “Realtime sysex” ON for automatic reading and auto-apply.
  • USB MIDI interface connected to the KN2000's MIDI port.

❓ Troubleshooting

  • KN2000 not listed in ports: check cable/interface, click 🔄 Ports.
  • Auto-read not working: check “Realtime sysex” is ON.
  • APC: knobs do nothing: check parameter assignments in the APC tab and the encoding mode.
  • Incomplete dump: a dump must total 5,184 bytes; run the dump again.
