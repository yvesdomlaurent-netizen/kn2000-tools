📖 Panel Console — Aide / Help

💡 Aide contextuelle (v1.0) : l'icône 📖 de chaque onglet ouvre cette page directement sur sa section (ancres stables pc-01-etat, pc-02-bibliotheque, pc-03-sons, pc-04-panel-memory, utilisables aussi comme références de documentation).

🚀 Démarrage rapide

  1. Ouvrir la page dans Chrome, Edge ou Firefox desktop (Web MIDI requis).
  2. Brancher l'interface MIDI USB du KN2000. Les ports mémorisés sont restaurés automatiquement (par nom) et la connexion testée par un « ping » ; sinon ouvrir ⚙️ Réglages → 🔌 Connexion, choisir In/Out puis 🔌 Connecter.
  3. Une fois connecté, l'état du clavier est lu automatiquement ; 🔄 Lire l'état le relit à tout moment (sonorités par part, rythme, tempo…).
  4. Ajuster les réglages à l'écran, puis ➤ Envoyer Tout pour les transmettre au clavier. Chaque section peut aussi être envoyée individuellement (▶).
💡 Le bouton 🔎 Moniteur (dans ⚙️ Réglages) affiche tout ce que le KN2000 envoie (CC, PC, sysex) — très utile pour découvrir des commandes non documentées.
💡 La case 📜 Log MIDI (en haut à droite) affiche le journal sysex de la session ; elle passe en surbrillance rouge si une erreur survient alors qu'il est masqué.

📚 Fonctions détaillées

Onglet ÉTAT

  • Sonorités par part : sélection par nom (listes déroulantes groupées) pour RIGHT 1 / RIGHT 2 / LEFT, avec volume, Digital Effect et DSP par part.
  • Rythme / tempo : sélection du rythme (envoyée au clavier), tempo affiché après lecture.
  • Reverb / DSP / Transpose / Techni-Chord / APC : pilotage direct, état rafraîchi par « Lire l'état ».
  • Panel Memory (ligne du haut) : ▶ Rappel rappelle la PM choisie sur le clavier, puis relit l'état.

Onglet BIBLIOTHÈQUE

  • 💾 Sauver l'état actuel : mémorise la configuration complète (nom libre) dans le navigateur (localStorage).
  • ▶ Charger : renvoie un ensemble sauvegardé vers le clavier (sons, rythme, volumes, effets…).
  • ⬇ Export JSON / ⬆ Import JSON : via le dossier de travail (voir ⚙️ Réglages → 📁) — l'export s'y écrit directement, l'import lit d'abord « kn2000-bibliotheque.json » ; repli fichier téléchargé / sélecteur si aucun dossier. Le dossier est partagé avec le Sound Editor.

Onglet SONS PART 4–16

  • Sound Setting des Part MIDI 4–16 (adresse sysex 20 1n 00) — utiles quand le KN2000 reçoit une séquence MIDI (canaux du menu Basic Channel).
  • Ce ne sont pas les sons des parts APC (ceux-ci viennent du rythme / Music Style).

Onglet PANEL MEMORY (avancé)

  • 📖 Lire cette PM : dump direct d'une Panel Memory (336 octets, méthode 2C) avec décodage lisible.
  • ➤ Écrire vers le clavier : réécrit la PM lue (confirmation demandée, écrasement possible vers une autre PM).
  • ↔ Diff 2 PM : compare les deux dernières PM lues octet par octet — révèle où un réglage (ex. son d'une part) est stocké dans la PM.
  • ⚙ Scanner adresses part APC : interroge les adresses sysex documentées (20 2m 02/07/40-43) puis les sons 20 1n 00 des Part 4–16.

🛠️ Réglages (menu ⚙️)

  • 🔌 Connexion : ports In/Out (mémorisés après « Connecter », restaurés par nom au prochain chargement), bouton 🔄 Ports, état de la liaison. Le test de connexion (DRQ léger) doit réussir avant toute lecture d'état.
  • 📁 Dossier de travail : dossier choisi une fois, mémorisé par le navigateur, partagé avec le Sound Editor — utilisé par l'export/import de la bibliothèque.
  • 🔎 Moniteur · 🌐 Langue · Aide : moniteur MIDI, bascule FR/EN des libellés de la charte, lien vers cette page.

❓ Dépannage

  • Aucun état ne s'affiche : vérifier les ports, « Realtime sysex » sur ON dans le KN2000.
  • « Réponse d'erreur du KN2000 : ERR 7E » (trame f0 50 29 7e) : le clavier refuse l'accès à l'adresse demandée (inexistante ou refusée) — vérifier « Realtime sysex » ON, et pour un dump PM, que la demande part bien après le 2C d'enable (20 04 00 01). Ce n'est pas un problème de câble : la machine répond.
  • Un réglage ne s'applique pas : utiliser « Diff 2 PM » pour vérifier si le réglage est bien stocké dans les Panel Memory.
  • Découvrir une commande : activer le Moniteur 🔍 et manipuler la même fonction sur le clavier.

🚀 Quick start

  1. Open the page in Chrome, Edge or Firefox 108+ desktop (Web MIDI required).
  2. Connect the KN2000's USB MIDI interface. Memorised ports are restored automatically (by name) and the link is tested with a "ping"; otherwise open ⚙️ Settings → 🔌 Connection, pick In/Out then 🔌 Connect.
  3. Once connected, the keyboard state is read automatically; 🔄 Read state re-reads it at any time (part sounds, rhythm, tempo…).
  4. Adjust the settings on screen, then ➤ Send All to transmit them to the keyboard. Each section can also be sent individually (▶).
💡 The 🔍 Monitor button (in ⚙️ Settings) shows everything the KN2000 sends (CC, PC, SysEx) — very useful to discover undocumented commands.
💡 The 📜 Log MIDI checkbox (top right) shows the session's SysEx log; it highlights in red when an error occurs while hidden.

📚 Detailed features

STATE tab

  • Part sounds: selection by name (grouped dropdowns) for RIGHT 1 / RIGHT 2 / LEFT, with per-part volume, Digital Effect and DSP.
  • Rhythm / tempo: rhythm selection (sent to the keyboard), tempo shown after the state read.
  • Reverb / DSP / Transpose / Techni-Chord / APC: direct control, state refreshed by “Read state”.
  • Panel Memory (top row): ▶ Recall recalls the chosen PM on the keyboard, then re-reads the state.

LIBRARY tab

  • 💾 Save current state: stores the full configuration (free name) in the browser (localStorage).
  • ▶ Load: sends a saved ensemble back to the keyboard (sounds, rhythm, volumes, effects…).
  • ⬇ Export JSON / ⬆ Import JSON: via the working folder (see ⚙️ Settings → 📁) — the export is written there directly, the import first reads “kn2000-bibliotheque.json”; fallback to a downloaded file / picker if no folder. The folder is shared with the Sound Editor.

SOUNDS PART 4–16 tab

  • Sound Setting of MIDI parts 4–16 (SysEx address 20 1n 00) — useful when the KN2000 receives a MIDI sequence (Basic Channel menu channels).
  • These are not the APC part sounds (those come from the rhythm / Music Style).

PANEL MEMORY tab (advanced)

  • 📖 Read this PM: direct dump of a Panel Memory (336 bytes, method 2C) with readable decoding.
  • ➤ Write to keyboard: rewrites the read PM (confirmation required, can overwrite another PM).
  • ↔ Diff 2 PM: byte-by-byte comparison of the last two Panel Memories read — reveals where a setting (e.g. a part's sound) is stored in the PM.
  • ⚖ Scan APC part addresses: queries the documented SysEx addresses (20 2m 02/07/40-43) then the 20 1n 00 sounds of parts 4–16.

🛠️ Settings (⚙️ menu)

  • 🔌 Connection: In/Out ports (memorised after “Connect”, restored by name on next load), 🔄 Ports button, link status. The connection test (light DRQ) must succeed before any state read.
  • 📁 Working folder: folder chosen once, memorised by the browser, shared with the Sound Editor — used by the library export/import.
  • 🔎 Monitor · 🌐 Language · Help: MIDI monitor, FR/EN charte label toggle, link to this page.

❓ Troubleshooting

  • No state displayed: check the ports and “Realtime sysex” ON on the KN2000.
  • “KN2000 error reply: ERR 7E” (frame f0 50 29 7e): the keyboard refuses the requested address (non-existent or denied) — check “Realtime sysex” ON, and for a PM dump that the request is sent after the enable 2C (20 04 00 01). It is not a cable issue: the machine is answering.
  • A setting does not apply: use “Diff 2 PM” to check whether the setting is actually stored in the Panel Memories.
  • Discovering a command: enable the 🔍 Monitor and operate the same function on the keyboard.
