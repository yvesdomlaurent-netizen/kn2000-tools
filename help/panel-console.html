📖 Panel Console — Aide / Help

🚀 Démarrage rapide

  1. Ouvrir la page dans Chrome, Edge ou Firefox desktop (Web MIDI requis).
  2. Brancher l'interface MIDI USB du KN2000, sélectionner les ports d'entrée/sortie.
  3. Cliquer 🔄 Lire l'état : la console relit la configuration courante du clavier (sonorités par part, rythme, tempo…).
  4. Ajuster les réglages à l'écran, puis ➤ Envoyer Tout pour les transmettre au clavier. Chaque section peut aussi être envoyée individuellement (▶).
💡 Le bouton 🔍 Moniteur affiche tout ce que le KN2000 envoie (CC, PC, sysex) — très utile pour découvrir des commandes non documentées.

📚 Fonctions détaillées

🎛️ Réglages pilotables

  • Sonorités par part : sélection par nom (listes déroulantes groupées) pour les parts du clavier.
  • Rythme / tempo : démarrage/arrêt, contrôle du tempo et reset.
  • Techni-Chord : modes (Off / OneFing / Fingered / Pianist) via les boutons dédiés.
  • Panel Memory : rappel (▶ Rappel) des Panel Memory, lecture (📖 Lire cette PM) et écriture (➤ Écrire vers le clavier) d'une PM.
  • Volumes / équilibres : réglages par section avec retour d'état.

🛠️ Fonctions avancées

  • État actuel : vue complète de l'état du clavier, rafraîchie par « Lire l'état ».
  • ↔ Diff 2 PM : compare les deux dernières Panel Memory lues octet par octet — révèle où un réglage (ex. son d'une part) est stocké dans la PM.
  • ⚖ Scanner adresses part APC : interroge les adresses sysex documentées pour l'APC (utile à l'exploration).
  • 💾 Bibliothèque d'ensembles : « Sauver l'état actuel » mémorise la configuration complète ; « ⬇ Export JSON » / « ⬆ Import JSON » pour partager ou sauvegarder des ensembles complets.
  • 📜 Log : journal MIDI/sysex de la session.

❓ Dépannage

  • Aucun état ne s'affiche : vérifier les ports, « Realtime sysex » sur ON dans le KN2000.
  • Un réglage ne s'applique pas : utiliser « Diff 2 PM » pour vérifier si le réglage est bien stocké dans les Panel Memory.
  • Découvrir une commande : activer le Moniteur 🔍 et manipuler la même fonction sur le clavier.

🚀 Quick start

  1. Open the page in Chrome or Edge desktop (Web MIDI required).
  2. Connect the KN2000's USB MIDI interface and select the input/output ports.
  3. Click 🔄 Read state: the console re-reads the keyboard's current configuration (part sounds, rhythm, tempo…).
  4. Adjust the settings on screen, then ➤ Send All to transmit them to the keyboard. Each section can also be sent individually (▶).
💡 The 🔍 Monitor button shows everything the KN2000 sends (CC, PC, SysEx) — very useful to discover undocumented commands.

📚 Detailed features

🎛️ Controllable settings

  • Part sounds: selection by name (grouped dropdowns) for the keyboard parts.
  • Rhythm / tempo: start/stop, tempo control and reset.
  • Techni-Chord: modes (Off / OneFing / Fingered / Pianist) via dedicated buttons.
  • Panel Memory: recall (▶ Recall), read (📖 Read this PM) and write (➤ Write to keyboard) of a Panel Memory.
  • Volumes / balances: per-section settings with state feedback.

🛠️ Advanced features

  • Current state: full view of the keyboard state, refreshed by “Read state”.
  • ↔ Diff 2 PM: byte-by-byte comparison of the last two Panel Memories read — reveals where a setting (e.g. a part's sound) is stored in the PM.
  • ⚖ Scan APC part addresses: queries documented SysEx addresses for the APC (useful for exploration).
  • 💾 Ensemble library: “Save current state” stores the full configuration; “⬇ Export JSON” / “⬆ Import JSON” to share or back up complete ensembles.
  • 📜 Log: MIDI/SysEx log of the session.

❓ Troubleshooting

  • No state displayed: check the ports and “Realtime sysex” ON on the KN2000.
  • A setting does not apply: use “Diff 2 PM” to check whether the setting is actually stored in the Panel Memories.
  • Discovering a command: enable the 🔍 Monitor and operate the same function on the keyboard.
