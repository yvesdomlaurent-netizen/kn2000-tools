# kn2000-tools
Un éditeur de sons Web MIDI pour le clavier Technics SX-KN2000 — dans le navigateur, sans installation. et Plus en cours

- Lecture/écriture des 36 slots Sound Memory (sysex, 144 octets par son, cartographie établie sur la machine)
- Édition temps réel par écrans (General/Tone/Effect), schémas d'enveloppe et de courbes
- Surface de contrôle Akai APC Key 25 mk2 (pads + knobs, LEDs)
- Dump banque, packages de sons (JSON), catalogue, sessions de création avec capture de l'original
- Compatible Chrome/Edge desktop (Web MIDI)

⚠️ Avant toute écriture : faire un dump de sauvegarde de la banque.

Fonctionne avec l'interface MIDI du KN2000. README détaillé (captures) à venir.
